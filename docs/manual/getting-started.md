# Hướng dẫn bắt đầu

Hướng dẫn nhanh để bạn làm quen với AutoMake.

## Bước 1: Mở ứng dụng

Chạy `AutoMake.App` từ Visual Studio 2026.

## Bước 2: Tạo workflow mới

Trên màn hình chính, nhấn **New Workflow** để tạo một quy trình trống.

## Bước 3: Thêm node

Kéo các node từ Toolbox vào bề mặt thiết kế. Ví dụ:
- Click chuột
- Nhập văn bản
- Chờ phần tử xuất hiện

## Bước 4: Kết nối node

Kéo từ cổng xuất của node này đến cổng nhập của node khác để tạo luồng thực thi.

## Bước 5: Lưu và chạy

Nhấn **Save** để lưu workflow, sau đó nhấn **Run** để bắt đầu thực thi.
