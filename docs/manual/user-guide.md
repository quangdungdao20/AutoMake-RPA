# Hướng dẫn sử dụng

Tài liệu này hướng dẫn cách sử dụng AutoMake – RPA Studio để thiết kế và thực hiện các quy trình tự động hóa.

## Giới thiệu

AutoMake cho phép người dùng thiết kế các quy trình tự động hóa trực quan thông qua Workflow Designer, hỗ trợ tự động hóa ứng dụng desktop và trình duyệt web.

## Tạo workflow đầu tiên

1. Mở `AutoMake.App` trong Visual Studio 2026.
2. Chạy ứng dụng và chọn **New Workflow**.
3. Kéo thả các node từ thanh công cụ vào khung thiết kế.
4. Kết nối các node để tạo luồng xử lý.

## Chạy workflow

Sau khi thiết kế xong, nhấn nút **Run** để thực thi workflow. Kết quả sẽ hiển thị ở bảng log trong ứng dụng.

## Xuất/nhập workflow

Workflow có thể được xuất sang file JSON/XML để lưu trữ hoặc chia sẻ với các thành viên trong nhóm.
