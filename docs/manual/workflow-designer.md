# Workflow Designer

Workflow Designer là công cụ trực quan để thiết kế các quy trình tự động hóa trong AutoMake.

## Các thành phần chính

- **Toolbox**: Danh sách các node có sẵn.
- **Canvas**: Bề mặt thiết kế để kéo thả và sắp xếp node.
- **Connections**: Đường nối giữa các node thể hiện luồng điều khiển.
- **Properties panel**: Cửa sổ chỉnh sửa thuộc tính của node được chọn.

## Cách thao tác

| Thao tác | Mô tả |
|----------|-------|
| Kéo thả node | Từ Toolbox vào Canvas |
| Kết nối node | Kéo từ cổng xuất đến cổng nhập |
| Xóa node | Nhấn phím Delete trên node đã chọn |
| Di chuyển node | Kéo node đến vị trí mới trên Canvas |

## Lưu workflow

Workflow được lưu dưới định dạng JSON/XML trong thư mục dự án.
