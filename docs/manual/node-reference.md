# Node Reference

Danh sách các node có sẵn trong Workflow Designer của AutoMake.

## Desktop Nodes

| Node | Mô tả |
|------|-------|
| Click | Nhấn chuột vào phần tử desktop |
| DoubleClick | Nhấn đúp chuột |
| TypeText | Nhập văn bản |
| PressKey | Nhấn phím bàn phím |
| WaitForElement | Chờ phần tử xuất hiện |
| GetText | Lấy văn bản từ phần tử |

## Browser Nodes

| Node | Mô tả |
|------|-------|
| OpenBrowser | Mở trình duyệt |
| ClickElement | Nhấn phần tử trên web |
| FillForm | Điền biểu mẫu web |
| ExtractData | Trích xuất dữ liệu web |
| WaitForNavigation | Chờ trang tải xong |
| Screenshot | Chụp ảnh màn hình |

## Control Flow Nodes

| Node | Mô tả |
|------|-------|
| If | Rẽ nhánh điều kiện |
| ForEach | Lặp qua danh sách |
| While | Lặp mà điều kiện đúng |
| Delay | Tạm dừng thực thi |

## Variable Nodes

| Node | Mô tả |
|------|-------|
| SetVariable | Gán giá trị cho biến |
| GetVariable | Lấy giá trị biến |
