# Browser Automation

Tự động hóa các thao tác trên trình duyệt web trong AutoMake.

## Các acción phổ biến

- **Open browser**: Mở trình duyệt với URL chỉ định.
- **Click element**: Nhấn vào một phần tử trên trang web.
- **Fill form**: Điền dữ liệu vào biểu mẫu web.
- **Extract data**: Trích xuất dữ liệu từ bảng hoặc danh sách.
- **Wait for navigation**: Chờ trang web tải hoàn tất.
- **Screenshot**: Chụp ảnh màn hình trình duyệt.

## Cách sử dụng

1. Kéo node **Browser Action** vào Workflow Designer.
2. Chọn loại tác vụ từ danh sách.
3. Cấu hình Selector để định vị phần tử trên trang web.
4. Lưu và chạy workflow.

## Locators

Hỗ trợ nhiều loại Selector: CSS Selector, XPath, ID, Name, Class, Text.
