# Cài đặt

Hướng dẫn cài đặt môi trường phát triển và chạy AutoMake.

## Yêu cầu

- .NET 10 SDK
- Visual Studio 2026 (có workload .NET Desktop)
- Windows 10/11 (64-bit)

## Cài đặt .NET 10 SDK

Tải xuống tại: https://dotnet.microsoft.com/download/dotnet/10

## Cài đặt Visual Studio 2026

1. Tải Visual Studio 2026 từ trang chủ Microsoft.
2. Trong trình cài đặt, chọn workload **.NET Desktop Development**.
3. Hoàn tất cài đặt.

## Clone source code

```bash
git clone https://github.com/your-org/AutoMake.git
cd AutoMake
```

## Mở solution

Mở file `AutoMake.slnx` bằng Visual Studio 2026, sau đó xây dựng solution (Build → Build Solution).
