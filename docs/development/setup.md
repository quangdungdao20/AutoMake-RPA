# Cài đặt môi trường phát triển

Hướng dẫn thiết lập môi trường để phát triển AutoMake.

## Các bước

1. Cài đặt .NET 10 SDK.
2. Cài đặt Visual Studio 2026 với workload .NET Desktop Development.
3. Clone repository và mở `AutoMake.slnx`.
4. Khôi phục các gói NuGet (Restore Packages).
5. Xây dựng solution (Build Solution).

## Kiểm tra

Chạy project `RPAStudio.Tests` để đảm bảo tất cả unit tests đều pass.
